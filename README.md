AXAC X KILLUA EDITION

A Killua-inspired Roblox Lua GUI featuring a dark interface, RGB styling, responsive controls, visual customization, and local utility features.

Features

- Responsive GUI and navigation
- RGB-inspired visual theme
- Customizable appearance settings
- Performance and visual utilities
- Character information
- Configurable interface controls
